# Arête

Static site. Connect this repo to Netlify:

1. [app.netlify.com](https://app.netlify.com) → Add new site → Import an existing project
2. Choose GitHub → `goomba929/arete`
3. Build command: leave empty
4. Publish directory: `.`
5. Deploy

You get a `something.netlify.app` link. Free. Scores stay on the phone.

On a phone: Share → Add to Home Screen.

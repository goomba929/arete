# Arête

Daily character sheet. Static site — no server, no Grok needed after you publish.

## Publish on Netlify (free)

1. Download `arete-netlify.zip`
2. Unzip it. You should see `index.html` in that folder.
3. Sign in at [app.netlify.com](https://app.netlify.com) (Drop is blocked until you are logged in).
4. Open [Netlify Drop](https://app.netlify.com/drop)
5. Drag the **unzipped folder** (not the zip) onto the page.
6. You get a live URL like `https://something.netlify.app`

## Or GitHub Pages (free)

Repo settings → Pages → Deploy from branch `main` → folder `/` (root).
